¿Qué es la especificidad en CSS?

La especificidad es el mecanismo que utiliza CSS para determinar qué regla de estilo tiene prioridad cuando varios selectores intentan modificar un mismo elemento HTML.

Cada selector tiene un nivel de prioridad. Cuanto más específico sea, mayor será su capacidad para determinar los estilos que se aplicarán.

Jerarquía de especificidad

Conoce los principales niveles de prioridad en CSS.

01. Estilos en línea

Son estilos que se escriben directamente en la etiqueta HTML mediante el atributo style. Tienen una prioridad alta frente a las reglas normales de una hoja CSS.

Ejemplo:
<p style="color: red;">
  Texto de ejemplo
</p>

02. Identificadores (ID)

Permiten seleccionar un elemento HTML específico mediante el atributo id. En CSS se representan utilizando el símbolo numeral (#).

Ejemplo:
#titulo {
  color: blue;
  font-size: 25px;
}

03. Clases y atributos

Identifican elementos mediante clases o características específicas. Se utilizan el punto (.) y los selectores de atributos.

Ejemplo:
.texto {
  color: green;
}

input[type="text"] {
  background: pink;
}

04. Pseudoclases

Permiten aplicar estilos dependiendo del estado de un elemento, como cuando el usuario pasa el cursor o selecciona un campo.

Ejemplo:
button:hover {
  background: purple;
}

input:focus {
  border: 2px solid blue;
}

05. Elementos y pseudoelementos

Los elementos seleccionan etiquetas HTML como p, h1 o div. Los pseudoelementos modifican partes específicas de un elemento.

Ejemplo:
p {
  color: black;
}

p::first-letter {
  font-size: 30px;
}

06. Selector universal (*)

Se representa mediante un asterisco y permite seleccionar todos los elementos HTML de una página. No aporta valor a la especificidad. 

* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

Resumen

De mayor a menor prioridad en las reglas normales:

  1. Estilos en línea.
  2. Identificadores (ID).
  3. Clases, atributos y pseudoclases.
  4. Elementos y pseudoelementos.

El selector universal y los combinadores no aportan especificidad.
